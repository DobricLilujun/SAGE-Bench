Python API

All public modules live under internscenes. The package uses lazy imports so import internscenes works even inside Blender's Python (which lacks optional dependencies).

Run the pipeline

"c-kw">from internscenes "c-kw">import pipeline

"c-kw">class="c-com"># whole pipeline "c-kw">for one scene
status = pipeline.run_scene("scannet/scene0313_00")
"c-kw">if status["status"] != "complete":
    "c-kw">raise RuntimeError(status)

"c-kw">class="c-com"># reuse verified existing output; skip Blender; use the VLM layer
pipeline.run_scene("scannet/scene0313_00", resume="c-kw">True, vlm="c-kw">True,
                   skip_render="c-kw">True, auto_fill="c-kw">False)

run_scene signature:

ParameterDefaultMeaning
resumeFalsereuse verified existing output
skip_render / skip_render_multi / skip_topdown / skip_graph / skip_questionsFalseskip a stage
vlmFalseapply the VLM annotation layer
auto_fillTruedownload missing models before compose
questions_n / questions_seed5 / Nonenavigation questions
plan_questionsFalsealso plan paths + render path top-downs

Scene-graph builder

"c-kw">from internscenes "c-kw">import scene_graph

graph = scene_graph.build_scene_graph(
    scene_id="scannet/scene0313_00",
    layout_path="data/Layout_info/scannet/scene0313_00/layout.json",
    vlm_result="c-kw">None,        "c-kw">class="c-com"># optional vlm_annotate result
    cfg="c-kw">None,               "c-kw">class="c-com"># optional relations.RelationConfig
    include_relative="c-kw">True,  "c-kw">class="c-com"># include left/right/front/behind
)
scene_graph.write_scene_graph(graph, "output/graph/scene_graph.json")
